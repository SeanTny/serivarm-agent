# 知识库索引

`knowledge/` 用于存放项目中的长期知识。

这里记录相对稳定的：

- 商业策略
- 选品方法
- Niche 方法
- 验证方法
- 品牌资料
- 当前业务状态

外部研究资料主要放在 `research/`。

重要商业决策主要放在 `decisions/`。

## 四、知识使用原则

处理任务时，不需要读取全部知识。

应该：

1. 先查看本索引
2. 根据任务选择相关知识
3. 阅读相关文件
4. 再开始工作

随着项目发展，本文件不断增加索引内容。
